# HANGAR-AD-03 — Motion Graphic Stüdyosu

Videolar [HyperFrames](https://github.com/heygen-com/hyperframes) ile HTML
kompozisyonlarından üretilir ve MP4 olarak `renders/` altına kaydedilir.

- `videos/<ad>/` — her videonun HyperFrames projesi
- `renders/<ad>.mp4` — çıktı
- `scripts/setup.sh` — HyperFrames + ffmpeg kurulumu
- `scripts/check-frames.sh` — render sonrası 12 kare kontrolü

Tasarım kuralları ve kontrol süreci: [CLAUDE.md](CLAUDE.md)
